# QUASAR dataset location

The dataset is intentionally not redistributed in this repository.

Run:

```bash
python download_dataset.py
```

or download the **Synthetic Quantum Circuit Reliability Dataset (QUASAR)**
from Kaggle and extract it into this directory:

<https://www.kaggle.com/datasets/ykmadhav/synthetic-quantum-circuit-reliability-dataset>

The loader finds the CSV containing `reliability_class`. The source file used
for the archived chapter run had SHA-256:

```text
506eff548af0603f771290cb75d3515f203d976162f3171b6494a1bb4d94025c
```

Downloaded files, manifests, and Kaggle credentials are ignored by Git.
